# EduQuest Android

Flutter dùng Supabase Auth, RPC, Realtime và Edge Functions. Xem [hướng dẫn triển khai và build APK](../TRIEN_KHAI_VA_BUILD_APK.md) trong thư mục gốc.

Cấu hình build cần `SUPABASE_URL` và `SUPABASE_PUBLISHABLE_KEY`. Chạy `flutter test` để kiểm tra luồng hồ sơ và đăng nhập với phản hồi API giả lập.
